## 0.1.0 — 2026-10-30

- Send a file from the terminal and get a six character code back
- Receive a file by typing the code on any other terminal
- Aesthetic terminal UI with QR code panel, short code block, and progress bar
- Resumable downloads, interrupted transfers pick up where they stopped
- Multiple files passed to send are zipped automatically
- End to end encryption with the short code as the key
- LAN discovery to transfer directly between two machines on the same network
- `junkyard doctor` checks your system and prints fixes
- `junkyard version --verbose` prints build info in a panel
- Documentation site with animated demo page
