See It Work

A transfer happens entirely in the terminal. The sender shares a code; the receiver types it in.

Terminal A — sender
$ junkyard send report.pdf
Transfer code: aB3cD9
Share this code with the receiver.
Waiting for connection...
Terminal B — receiver
$ junkyard receive aB3cD9
Receiving report.pdf (245 KB)…
✔ Saved to ./report.pdf

The flow

  1. The sender runs junkyard send <file>.
  2. Junkyard prints a six-character transfer code.
  3. The code is shared separately (chat, email, spoken).
  4. The receiver runs junkyard receive <code>.
  5. The file downloads through the relay and is saved locally.
QR-assisted handoff

When a QR renderer is available, the sender also displays a QR code. The receiver can scan it instead of typing the six characters.
