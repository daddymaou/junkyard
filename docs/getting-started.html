Getting Started

Install Junkyard, start the relay server, and run your first transfer.

1. Install

Junkyard is a single Go CLI. Install from source:

shell
go install github.com/daddymaou/junkyard/cmd/junkyard@latest

This builds the junkyard binary into $GOBIN (usually ~/go/bin). Make sure that directory is on your PATH.

2. Start the server

Both terminals connect to a relay you run. Start it on the machine that can be reached by both sides:

shell
junkyard server

By default it listens on localhost:45845. Use --listen to bind to a different address if the sender and receiver are on different machines.

3. Send a file

From the sending terminal:

shell
junkyard send document.pdf

Junkyard prints a six-character transfer code and (optionally) a QR code. Share that code with the recipient — separately from the file.

4. Receive the file

From the receiving terminal:

shell
junkyard receive <code>

Enter the six-character code. The file downloads through the relay and is written to your current directory (or a path you choose with --output).

Multiple files

Pass several files to junkyard send and they are packaged into a ZIP archive automatically:

junkyard send file1.txt file2.pdf image.png
