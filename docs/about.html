About

Junkyard is a command-line file transfer tool for sending a file from one terminal and receiving it in another.

The sender gets a six-character code; the receiver uses that code to retrieve the file. A QR code is available when scanning is easier than typing.

No account or browser upload form is part of the workflow. Junkyard consists of a CLI and a transfer server; it does not come with a hosted relay service.
