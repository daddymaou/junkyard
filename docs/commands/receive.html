junkyard receive

Receive a file using a transfer code.

shell
junkyard receive [code]

Purpose

Enter the six-character transfer code from the sender. Junkyard downloads the file through the relay and writes it to your current directory, or to a path you choose with --output.

Examples

shell
# Receive a file (prompts for the code)
junkyard receive

# Receive with a code directly
junkyard receive AB12CD

# Save to a specific path
junkyard receive AB12CD --output ~/Downloads/document.pdf

What happens

  • The client derives the encryption key from the short code.
  • Encrypted chunks are downloaded from the relay and verified before writing.
  • Interrupted downloads can resume from the saved byte offset.
Not end-to-end from the relay

The relay receives the short code used to derive the encryption key. For sensitive transfers, run a relay you control.
