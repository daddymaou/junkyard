junkyard server

Run the Junkyard transfer server.

shell
junkyard server

Purpose

The server is the relay that moves file data between the sender and receiver. Both terminals must be able to reach it. By default it listens on localhost:45845.

Examples

shell
# Run on the default address
junkyard server

# Bind to a specific address so other machines can connect
junkyard server --listen 0.0.0.0:45845

Scope

  • Junkyard does not operate a hosted relay service.
  • No user accounts, no browser upload form, no public file transfer.
  • Run your own relay for sensitive transfers.
Reachability matters

If the sender and receiver are on different machines, the server must listen on an address both can reach (for example 0.0.0.0:45845 on a host reachable over your network).
