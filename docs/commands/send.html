junkyard send

Send one or more files and display a transfer code.

shell
junkyard send <file...>

Purpose

Send one file, or pass multiple files to package them into a ZIP archive. The command prints a six-character transfer code and, when a QR renderer is available, a QR code the receiver can scan instead of typing.

Examples

shell
# Send a single file
junkyard send document.pdf

# Send multiple files (packaged as ZIP)
junkyard send file1.txt file2.pdf image.png

# Send from a specific path
junkyard send ~/Desktop/report.pdf

What happens

  • The client encrypts file chunks before upload.
  • A six-character code is generated from Go's cryptographic random source.
  • The file (or ZIP archive) is uploaded to the relay server.
  • The code is printed to your terminal — share it with the receiver.
Code is separate from the file

The transfer code is not embedded in the file. Share the code however you prefer — chat, email, or read it aloud. The receiver enters it with junkyard receive.
